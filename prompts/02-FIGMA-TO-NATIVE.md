# Figma-to-native prompt

```text
Implement ONLY screen [Ixx or Axx] from the exact relevant BeforeTap Figma file.
iOS: https://www.figma.com/design/W7mn2g5KWER37FEFTeCal9
Android: https://www.figma.com/design/TeWROoR3LlljunpY0j6Vvc

Inspect the requested screen and navigation states in Figma if access exists.
If no Figma access, say so and ask for a screenshot/spec; never invent pixel values.
Use system-native components and accessibility semantics, not screenshot overlays.
iOS: system tabs/toolbars and Liquid Glass sparingly; Android: Compose Material 3.
Provide previews, screenshot comparison, empty/loading/error states and tests.
Avoid replacing existing architecture or adding an unsupported live scan.
```
