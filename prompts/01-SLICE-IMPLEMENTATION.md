# One-slice implementation prompt

```text
Work on ONLY [MILESTONE / ONE TESTABLE SLICE].
Read AGENTS.md, STATUS.md, the relevant docs and platform Figma link.
Do not expand to adjacent features.

Before code: give a 5-line plan, exact files, behavior, failure states, and test.
Implement with native APIs and minimum dependencies.
For security-related code, include adversarial cases and fail-closed behavior.
Run all available focused tests and build; report exact commands and results.
Never claim a demo or unimplemented provider is live.
Update STATUS.md and the relevant ROADMAP.md checkbox only if verified.
Provide a concise diff summary and next proposed slice.
```
