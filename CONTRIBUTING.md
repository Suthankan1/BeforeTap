# Development workflow

This project is currently owner-directed. The repository is not explicitly licensed for third-party contributions.

1. Read `AGENTS.md`, relevant docs and `STATUS.md`.
2. Make a new branch for one `ROADMAP.md` slice.
3. Keep platform-native UI and security semantics consistent.
4. Add focused tests and compare screenshots against the correct Figma file.
5. Do not include secrets, sensitive real user inputs or live malicious domains.
6. In PR/review, list actual commands, device/OS versions, screenshot evidence, accessibility checks and unverified items.
7. Update `STATUS.md` and, for accepted decisions, `DECISIONS.md`.

Do not check off a milestone merely because an AI tool generated code.
