# Feature cycle

1. Read `AGENTS.md`, `STATUS.md`, `ROADMAP.md` and the relevant specification.
2. Define one small vertical slice, files, acceptance criteria, risk and exact tests.
3. Implement with native APIs and mocks only where explicitly labeled.
4. Test the happy path, error state, accessibility and privacy boundary.
5. Summarize verified outcomes and remaining gaps.
6. Update `STATUS.md`; add an entry to `DECISIONS.md` only for a meaningful choice.
7. Stop for human review before expanding scope.
